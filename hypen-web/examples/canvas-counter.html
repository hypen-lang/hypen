🎨 Canvas Renderer Demo

Canvas 2D No DOM Hypen Framework

This counter is rendered entirely on a <canvas> element using the Canvas 2D API. No DOM elements are created for the buttons or text - everything is drawn pixel by pixel!

Features:

  • ✅ Flexbox-like layout system
  • ✅ Hit testing for mouse events
  • ✅ Hover states and cursor changes
  • ✅ Text rendering with wrapping
  • ✅ Accessibility via shadow DOM
