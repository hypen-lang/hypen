# hypen-example-pricing

Hypen example: a pricing module built to a WebAssembly Component

## Install

```bash
hypen add hypen-example-pricing
```

`hypen add` shows what each module below asks for and records what you grant in your app's `hypen.json`.
Nothing in this package runs at install time.

## Use

- `Pricing {}` in a template

## Modules and the capabilities they request

### Pricing

- read the state of the Cart module
- dispatch actions to the Cart module — **it can run Cart's action handlers**

_Generated by `hypen pack` from hypen-modules.json (hypen-example-pricing 0.1.0)._
