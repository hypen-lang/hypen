# Server SDKs

Hypen supports server-side rendering where the engine runs on your server and streams UI patches to clients over WebSocket.

## Architecture

```
┌─────────────────────────────────────────────────────┐
│  Your Server (Bun/Go/Kotlin/Swift/Rust)             │
│  • Runs the Hypen engine (WASM or native)           │
│  • Manages state and business logic                 │
│  • Streams UI patches over WebSocket                │
└─────────────────────────────────────────────────────┘
                      │ WebSocket
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
   ┌─────────┐   ┌─────────┐   ┌─────────┐
   │   Web   │   │ Android │   │   iOS   │
   │ Browser │   │   App   │   │   App   │
   └─────────┘   └─────────┘   └─────────┘
```

## How It Works

1. **Client connects** via WebSocket
2. **Server initializes** the engine with your module and UI template
3. **Initial render** — server sends the full UI tree as patches
4. **User interacts** — client sends action messages to the server
5. **State updates** — server processes actions, updates state, and diffs the UI
6. **Patch streaming** — only the changed elements are sent to the client

## Benefits

- **One codebase** — Write once, render on web, Android, and iOS
- **Thin clients** — Clients just apply patches, no WASM needed on device
- **Server-side state** — Easy to persist, secure, and share between users
- **Hot updates** — Change UI without app store updates
- **Session management** — Clients can disconnect and reconnect without losing state

## Available SDKs

| SDK | Language | Package | Where to get it |
|-----|----------|---------|-----------------|
| [TypeScript](/docs/servers/typescript) | TypeScript (Bun) | `@hypen-space/core`, `@hypen-space/server` | npm |
| [Go](/docs/servers/golang) | Go 1.25+ | `github.com/hypen-lang/hypen/hypen-golang` | `go get github.com/hypen-lang/hypen/hypen-golang@v0.6.7` |
| [Kotlin](/docs/servers/kotlin) | Kotlin/JVM | `space.hypen:hypen-kotlin` | Maven Central (`space.hypen:hypen-kotlin:0.6.7`, native engine bundled) |
| [Swift](/docs/servers/swift) | Swift | `HypenServer` | Not published; local package from the repository |
| [Rust](/docs/servers/rust) | Rust | `hypen-server` | crates.io (0.6.x) |
| [Cloudflare](/docs/servers/cloudflare) | TypeScript (Workers) | `@hypen-space/cf` | npm |

The TypeScript SDK is the primary one: `hypen init`, `hypen dev` and Studio are built on it.

## Quick Start

```typescript
import { app } from "@hypen-space/core";
import { serve } from "@hypen-space/server";

const module = app
  .defineState({ count: 0 })
  .onAction("increment", ({ state }) => {
    state.count++;
  })
  .build();

await serve({
  module,
  ui: `
    Column {
      Text("Count: @{state.count}")
      Button { Text("+1") }
        .onClick(@actions.increment)
    }
  `,
  port: 3000,
});
```

Run it with `bun run server.ts` and open http://localhost:3000 for the built-in web client, or connect any Hypen client to `ws://localhost:3000`.
