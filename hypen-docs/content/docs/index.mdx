# Hypen Documentation

Hypen is a declarative UI language designed for cross-platform application development. Write your UI once and render it natively on Web, Android, iOS and desktop.

## Why Hypen?

- **One Codebase, All Platforms**: Define your UI once and render natively on Web, Android, iOS and desktop
- **Native Performance**: Renders to platform-native components, not WebViews
- **Simple Syntax**: Intuitive, declarative syntax that's easy to learn
- **Reactive by Design**: Automatic UI updates when state changes
- **Type-Safe Modules**: TypeScript-powered state management and actions

## Quick Example

```hypen
module HelloWorld {
    Column {
        Text("Hello, @{state.name}!")
            .fontSize(24)
            .fontWeight("bold")

        Input(placeholder: "Enter your name")
            .label("Your name")
            .bind(@state.name)
            .padding(12)
            .borderRadius(8)
    }
    .padding(24)
    .gap(16)
}
```

```typescript
// HelloWorld/component.ts
import { app } from "@hypen-space/core";

export default app
  .module("HelloWorld")
  .defineState({ name: "World" })
  .build();
```

`.bind(@state.name)` keeps the input and `state.name` in sync, so the greeting updates as you type. No action handler is needed.
