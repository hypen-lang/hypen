# Getting Started

Welcome to Hypen! Write your UI once and run it natively on Web, Android, iOS and desktop, all from a single codebase.

## Develop Anywhere, Run Everywhere

Hypen gives you a complete development workflow out of the box. The CLI runs on [Bun](https://bun.sh); inside a project, run these through the project's scripts (`bun run dev`) or `bunx hypen ...`:

- **`hypen dev`** — Start a hot-reloading dev server and preview in the browser
- **`hypen studio`** — Open a full in-browser IDE with live preview, state inspector, time-travel debugging, and an integrated terminal
- **`hypen run android`** — Preview your app on an Android device or emulator with hot reload
- **`hypen run ios`** — Preview your app on the iOS Simulator with hot reload
- **`hypen run desktop`** — Preview in Hypen Browser, the native desktop runner (downloaded on first run)
- **`hypen run android --studio`** — Edit in Studio and preview on a device at the same time

You can go from zero to running on web and mobile in minutes.
