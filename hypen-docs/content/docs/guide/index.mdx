## Quick Reference

### Component Syntax

```hypen
// Basic component
Text("Hello World")

// Component with children
Column {
    Text("First")
    Text("Second")
}

// Component with children and applicators
Button { Text("Save") }
    .onClick(@actions.save)
```

### Applicator Syntax

```hypen
Text("Styled")
    .fontSize(18)
    .fontWeight("bold")
    .color("#3B82F6")
```

### State Bindings

```hypen
Text("Count: @{state.count}")
```

### Actions

```hypen
Button { Text("+1") }
    .onClick(@actions.increment)
```

### Control Flow

```hypen
// Iteration
ForEach(items: @state.items) {
    Text(@item.name)
}

// Pattern matching
When(value: @state.status) {
    Case(match: "loading") { Spinner() }
    Case(match: "error") { Text("Error") }
    Else { Text("Ready") }
}

// Boolean conditional
If(condition: @state.isVisible) {
    Text("Visible")
    Else { Text("Hidden") }
}
```
